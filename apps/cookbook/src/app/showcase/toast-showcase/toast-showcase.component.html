Toasts are the most subtle 'notification' available in Kirby. These messages give users immediate feedback after taking an action. Users don't need to dismiss toast messages, as they appear only for a moment before they disappear.

There are two types of toasts:

  • Success is used for confirmations on an action
  • Warning is used for warnings, eg. something the user should be aware of

Default

By default, toasts will automatically dismiss after 4 seconds (4000ms).

Duration

You can customize how long the toast is displayed using the durationInMs property. Set it to 0 to keep the toast visible until it is dismissed programmatically.

Programmatic Dismiss

The showToast() method returns a Promise<Overlay> that resolves to an overlay object. You can use this to dismiss the toast programmatically by calling dismiss() .

Callback

If you need to know when the toast is dismissed, you can pass a callback function as the second argument:

this.toastController.showToast(config, () => {{ '{' }} console.log('Toast was dismissed'){{ '}' }});

Best Practice

  • Use a toast when
    • it is not critical for the user to read the message.
    • you don't have clear instructions and/or the user can find the given information in the screen shown.
  • Keep the amount of text below 1 line.
