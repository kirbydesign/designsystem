Accessibility

An accessible name should generally be added to help screen reader users understand the purpose and content of th progress circle. It can be provided using either the aria-labelledby if a visual label is present, or aria-label if only an accessible name is needed for your progress-circle element

It is possible to provide an accessible name for your progress circle using the aria-label aria-labelledby attribute on the progress-circle element.

The label you provide will be announced together with the progress circle.
