Pad precision digits

Setting [padPrecisionDigits]="true" ensures that the input value always has the number of fractional digits as specified by the precision property, even if the user enters fewer digits. For example, a value of "3.5" will automatically render as "3.50".

Date

The value supplied to the input should be formatted according to the current locale.

Please note: The input UI generally varies between browsers and between devices ( MDN ). This may not adhere to the visual preferences for your project.

However, a platform native date picker has several advantages out of the box, such as being accessible and having built-in localization.

When opting into the native datepicker, the value should be in the Date strings format .
