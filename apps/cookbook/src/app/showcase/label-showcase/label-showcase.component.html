Label is a layout element used to structure text content inside Items. Recommended use of label and its differences from the HTML-label element are illustrated in the following examples.

In Item

Label direction

By default the text inside the label is vertically stacked. Setting the direction property to horizontal aligns the text horizontally. This is useful for composing items with multiple labels where some of them should be aligned next to each other.

Other label types

Despite its naming, the label component is not to be confused with the HTML-element, which has an entirely different purpose of associating a label text with a form control.

In Kirby the behavior of the HTML-label element is achieved by using the form-field component, where a label element is automatically rendered under-the-hood around the supplied form controls (input, checkbox, radio-group etc.).

More information about the advantages of this approach can be found in the MDN label documentation .
