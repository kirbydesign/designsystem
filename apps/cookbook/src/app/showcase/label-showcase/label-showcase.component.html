Other label types

Despite its naming, the kirby-label component is not to be confused with the HTML-element, which has an entirely different purpose of associating a label text with a form control.

The behavior of the HTML-label element is achieved by using the form-field element, where a label element is rendered under-the-hood around the supplied form controls (input, checkbox, radio-group etc.).

More information about the advantages of this approach can be found in the MDN label documentation .
