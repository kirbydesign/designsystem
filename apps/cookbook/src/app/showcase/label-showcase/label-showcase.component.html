A kirby-label is a layout element used to structure text content inside Items. Recommended usage of Kirby-label and the standard label are illustrated in the following examples. Kirby-label should be used in item components and label should be used in form fields.

Other label types

Despite its naming, the kirby-label component is not to be confused with the HTML-element, which has an entirely different purpose of associating a label text with a form control.

In fact, when you are using the form-field element, a native label element is rendered under-the-hood around the supplied kirby components (input, checkbox, radio-group etc.)

More information about the advantage of this approach can be found in the MDN label documentation .
