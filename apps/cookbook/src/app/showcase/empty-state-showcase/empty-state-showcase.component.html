The Empty State provides feedback to the user while, if possible, giving constructive guidance about next steps.

Message Types

The empty state supports different types of messages via the themeColor input.

Buttons

If the empty state acts as a call to action, one or more buttons can be added.

If the first button has attention-level 1, that level will be preserved. Any additional buttons will be adjusted to attention-level 3 regardless of their initial attention-level.
