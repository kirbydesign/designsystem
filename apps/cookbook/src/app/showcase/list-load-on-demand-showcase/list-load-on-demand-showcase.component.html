The kirby list will emit a loadOnDemand event, when the user has scrolled 80% of the list. It is the responsibility of the consumer to add more items to the bound items .

If the list does not fill the view, e.g. on a page or in a modal that cannot scroll, the event is also emitted without scrolling, until the content becomes scrollable. This is checked initially, after complete() is called and when items changes. Assign a new array to items (instead of mutating it) for the change to be detected.

The event emitted is of type LoadOnDemandEvent which exposes a complete() callback function.

The complete() callback function should be called when the loading of the additional items are done.

If complete(disableLoadOnDemand?: boolean) is called with the disableLoadOnDemand argument set to true , no further events will be emitted. If noMoreItemsText is configured it will be shown at the end of the list at this point.

Accessibility

It is possible to provide an accessible name for your list using the aria-label or aria-labelledby attribute on the kirby-list element. More information can be found in the list showcase.
