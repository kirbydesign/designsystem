Items are elements that contain text, icons, avatars and controls such as checkboxes. They are mainly used to structure similar content in a list together with other items.

Sizes

Items can be displayed in different sizes, depending on the need for visual space around the content. It can be controlled with the size property. Accepted values are xs , sm or md . The default size is md .

Text

Items display paragraphs as a single line of text, and the text is truncated with an ellipsis if it exceeds available space. By adding the class kirby-item-wrap text will wrap to the next line.

Vertically stacked texts

Items can display multiple lines of content using the kirby-label component.

The appearance of text content can be adjusted using the kirby-item-title , kirby-item-subtitle and kirby-item-detail css classes.

Complex label structures

Items can display complex label structures using multiple kirby-label elements. When multiple labels are combined, the direction property of the label can be used to, as in this example, horizontally align the title text with some other element like a related date.

Slots

In addition to the default slot, content can be placed in the start , end , or outside slots.

Selectable & Disclosure

The selectable property should be added to items when some action is bound to the item with a click listener or similar. The selectable property will add hover, focus and active states to the item.

Generally, a disclosure indicator should be added on items that navigate to a new page or activates a modal or similar overlay.

Disabled

Selectable items can be disabled, to prevent the user from activating them.

Nested Controls

Items can contain nested controls, such as checkboxes or radio buttons.

Avoiding nested interactives

Nested interactives are interactive elements, such as buttons or links, placed inside other interactive elements. This can lead to accessibility issues and unexpected behavior, as browsers and assistive technologies will handle them inconsistently if at all.

To avoid issues with nested interactives in selectable items, ensure that interactive controls are not placed inside selectable items.

When a button, checkbox or similar is nested inside an item, the item should never be marked as selectable.

Disabled Nested Controls

Since items with nested controls should not be selectable, they cannot be disabled either. Instead, any nested control itself should be disabled so users of Assistive Technology can still explore the remaining item content.
