Items are elements that contain text, icons, avatars and controls such as checkboxes. They are mainly used to structure similar content in a list together with other items.

Sizes

Items can be displayed in different sizes, depending on the need for visual space around the content. It can be controlled with the size property. Accepted values are xs , sm or md . The default size is md .

Text

By default, items display paragraphs as a single line of text, and the text is truncated with an ellipsis if it exceeds available space. By adding the class kirby-item-wrap

Vertically stacked texts

Items can display multiple lines of content using the kirby-label component.

Slots

Content can be placed in the start , end , or outside slots for specific layouts.

Selectable & Disclosure

Disclosure indicators should be used on items with a related action or navigation, to inform the user that clicking them will open a modal, navigate to a new page or similar.

Avoiding nested interactives

Nested interactives are interactive elements, such as buttons or links, placed inside other interactive elements. This can lead to accessibility issues and unexpected behavior, as browsers and assistive technologies will handle them inconsistently if at all.

To avoid issues with nested interactives in selectable items, ensure that interactive controls are not placed inside selectable items.

When a button, checkbox or similar is nested inside an item, the item should never be marked as selectable.

Disabled

Selectable items can be disabled, to prevent the user from activating them.

Nested Controls

Items can contain nested controls, such as checkboxes or radio buttons.

Selectable and Disabled

Items with nested controls should not be marked as selectable or disabled, and item will ignore any selected state added if a nested kirby control exist.

Instead of marking the item as disabled, any nested control should be disabled, so users of assistive technologies can still explore the item content, and get notified of possible actions.
