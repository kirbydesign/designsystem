A dropdown is a compact way of displaying multiple choices from which a user can select one option. It appears upon interaction with an element (such as an icon or button). A selected option can represent a value in a form, or can be used as an action to filter or sort existing content.

Simple

Default

The default dropdown displays a list of options with no pre-selected value.

Sizes

There are two available sizes. While they are generally interchangeable, it is important to use them consistently.

  • Medium ( md ) typically used when only one or a few dropdowns are needed in a view.
  • Small ( sm ) typically used in smaller areas or when there is a need to fit multiple dropdowns within the content area.

States

States reflect the dropdowns current status, providing visual feedback to the user.

The three following states are supported, alongside hover and focussed state on interactions with mouse and keyboard.

  • Enabled
  • Disabled
  • Error

In Form Field

Dropdowns can be placed within a <kirby-form-field> and assigned a label and an optional message.
Clicking the label toggles the open/closed state of the dropdown.

Validation
If validation for the field fails you can set the hasError property of <kirby-dropdown> (and optionally an error message through the message property of <kirby-form-field> ).

Scroll

The dropdown becomes scrollable if it contains more than 8 items.

Pre-selected

Use this if you want an initial preselected item.

Block level

To display the dropdown in full width of its container, apply block-level styling to the dropdown.

Right aligned

The dropdown can be right aligned, so the list of items appear along the right-most edge of the trigger button.

Attention level

Applying an attention level changes the background color to help draw attention to the dropdown.

Event handler

The dropdown can be used with an event handler to perform an action when an item is selected.

Advanced

Custom Item template

Custom item templates can be used to create more complex layouts for each option in the dropdown, allowing for enhanced flexibility and design.

Forms

The dropdown can be used with Angular forms. This allows you to use the dropdown as a form control and bind it to a form model.

Best Practices

  • Use a dropdown when there are multiple choices that can be collapsed under one title, if the list of items is too long, or when space is constrained.
  • Use a dropdown when the selected option is more important than the alternatives (in contrast to radio buttons where all the choices are visible, putting equal emphasis on all options).
  • Don't use a dropdown if there are two options to choose from. In this case, use a radio button group instead.
  • If it isn't possible to have a default selected choice, then show a guiding placeholder text

Accessibility

The Dropdown implements the Select-only Combobox Pattern from ARIA Authoring Practices Guide.

When used without a surrounding form-field, an accessible name provided with either an aria-label or aria-labelledby attribute is needed to ensure screen readers announce the dropdown correctly.

Keyboard support

The component has full keyboard support for opening the dropdown and navigating between and selecting items in the dropdown.

The following keys can be used to open the dropdown when the dropdown button has focus:

  • Enter, Space, Alt + ↓ and Home opens dropdown and moves focus to the first dropdown item if no selection.
  • End opens dropdown and moves focus to the last dropdown item.
  • ↑ opens dropdown and moves focus to first dropdown item.
  • ↓ opens dropdown and moves focus to the last dropdown item.
  • A-Z opens the dropdown and moves focus to the first option that matches the typed character. If multiple keys are typed in quick succession, focus moves to the first option that matches the full string. If the same character is typed in succession, visual focus cycles among the options starting with that character.

The following keys can be used to navigate and select within the dropdown:

  • Enter and Space sets value of focused item and closes the dropdown.
  • Escape closes the dropdown.
  • ↑ moves focus to the previous dropdown item. If focus is on the first dropdown item, focus will not move.
  • ↓ moves focus to the next dropdown item. If focus is on the last dropown item, focus will not move.
  • Alt + ↑ sets value of focused item and closes the dropdown.
  • Home moves focus to the first dropdown item.
  • End moves focus to the last dropdown item.
  • PageUp jumps focus up 10 options (or to first option).
  • PageDown jumps focus down 10 options (or to last option).
  • A-Z opens the dropdown and moves focus to the first option that matches the typed character. If multiple keys are typed in quick succession, focus moves to the first option that matches the full string. If the same character is typed in succession, visual focus cycles among the options starting with that character.
  • Tab sets value of focused item, closes the dropdown and moves focus to the next element in the tab sequence outside the control.
