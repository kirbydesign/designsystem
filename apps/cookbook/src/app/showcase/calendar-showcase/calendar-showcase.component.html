The calendar is a picker interface that displays a date grid with month navigation, for users to select a single date. By default any date is accepted but various configurations can be applied to restrict what dates users can select.

Calendar in card

Calendar with year navigator

A year-navigator can be shown in the calendars header for users to easily jump back and forward by one year.

Calendar without background

The calendar comes with minimal styling out of the box and we recommend to place it in a kirby-card .

In some rare use-cases it can be necessary to place the calendar on a different background or directly on canvas, in which case the calendar can be used without any surrounding card.

Specifying locale

The locale of the calendar (i.e. day and month names) can be set by providing a LOCALE_ID . The calendar currently supports LOCALE_IDs da , en-GB and en-US and it defaults to en-GB if none is provided.
