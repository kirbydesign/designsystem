An accordion is a vertically stacked list of headers that reveal or hide related sections of content.

Setup

Accordions use Angular animations for animating between its collapsed and expanded state. As no other components depend on the package it is not bundled with Kirby for performance reasons and should instead be provided in the application as detailed in the Angular docs for enabling the animations module .

With initially expanded item

It is possible to have an accordion expanded initially to draw attention to specific information.

Accordion inside a card

The accordion can be wrapped in a Kirby Card to make it stand out from the canvas.

Accordion with list

Placing a list within an accordion item will automatically adapt spacing and strip the necessary list-styling to ensure that the list looks correct without further adjustments.

Additional styling

Similarly to the simple accordion, the accordion with a list can also be wrapped in a Kirby Card to make it stand out from the canvas.

Accordion toggle event

A toggle event is emitted whenever an accordion is expanded or collapsed.

Accessibility

To enhance accessibility and improve screen reader navigation, a headingLevel can be assigned to the accordion headers to include them in the pages heading structure. Heading levels can be controlled for all accordion items by setting the heading level on the <kirby-accordion> , but for more fine-grained control, it can be set individually on each item instead.
