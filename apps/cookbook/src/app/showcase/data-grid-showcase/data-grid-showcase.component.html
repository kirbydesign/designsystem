The data grid displays complex, related data in rows and columns. It is under development and not ready for use.

Default data grid

Sorting

Register rowSortingFeature and every header becomes sortable. Turn it off for a column with enableSorting: false . The example sorts on the server: the table only holds the sorting state, the backend returns the rows in order, and manualSorting: true renders them as received. The other options give Kirby's sorting behavior: start ascending, then toggle between ascending and descending, and sorting another column replaces the current one.

Selection

Register rowSelectionFeature and add kirbyDataGridSelectionColumn to the columns. It adds a select-all checkbox in the header and one checkbox per row. rowLabel is required: it names each checkbox for screen readers, for example "Select Acme A/S". Selection is keyed by getRowId , so it survives sorting and reloads. Which rows can be selected is a table option, for example enableRowSelection . Only the checkbox selects a row; clicking the row itself does not.
