Typography utility classes and individual tokens can be used for consistent, accessible text styles.

Utility Classes

These CSS classes combine font-size, font-weight, and line-height tokens into ready-to-use text styles, that can be applied to any element.

Some of the classes correspond directly to the global styles for semantic tags, and can be used to give e.g. a heading level 3 a visual appearance that matches a heading level 2 instead.
