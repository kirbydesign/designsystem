# Accessibility Utilities

Accessibility utilities provide directives that enhance the accessibility of common HTML elements. These utilities ensure compliance with accessibility standards and improve user experience, particularly for keyboard and screen reader users.

## Anchor As Button

The `AnchorAsButtonDirective` allows usage of anchors without the `href` property (that to open a modal or an alert through the `(click)` event, for instance) while still being accessible.
